## The Energy Management Stack

For a homeowner to fully manage energy, they need certified installers for:

```
┌─────────────────────────────────────────────────────────────────────┐
│                    ENERGY GENERATION                                │
│  Solar Panels → Inverters → Microinverters                         │
│  (Enphase, SolarEdge, Tesla) ✅ HAVE THESE                         │
├─────────────────────────────────────────────────────────────────────┤
│                    ENERGY STORAGE                                   │
│  Home Batteries → Wall-mounted → Stacked systems                   │
│  (Tesla Powerwall, Sonnen ✅, Enphase, FranklinWH, LG RESU)        │
├─────────────────────────────────────────────────────────────────────┤
│                    ENERGY DISTRIBUTION                              │
│  Smart Panels → Load Management → Circuit Control                  │
│  (SPAN, Lumin, Schneider Square D, Savant, Eaton, Leviton)         │
├─────────────────────────────────────────────────────────────────────┤
│                    ENERGY CONSUMPTION                               │
│  EV Chargers → HVAC/Heat Pumps → Water Heaters                     │
│  (Wallbox, ChargePoint, Tesla Wall Connector)                      │
├─────────────────────────────────────────────────────────────────────┤
│                    ENERGY INTELLIGENCE                              │
│  Smart Thermostats → Home Automation → Energy Monitors             │
│  (Nest, ecobee, Honeywell, Control4, Savant, Lutron)               │
├─────────────────────────────────────────────────────────────────────┤
│                    BUILDING ENVELOPE                                │
│  Roofing → Insulation → Windows                                    │
│  (GAF, CertainTeed, Owens Corning, Malarkey)                       │
├─────────────────────────────────────────────────────────────────────┤
│                    SECURITY & LOW VOLTAGE                           │
│  Alarm Systems → Cameras → Access Control                          │
│  (Alarm.com, Ring, Vivint, ADT, Control4)                          │
└─────────────────────────────────────────────────────────────────────┘
```

## TIER 1: HIGH PRIORITY - Strong ICP Signal + Public Locators

### 1. SPAN - Smart Electrical Panels
- **URL:** https://www.span.io/get-started (form-based matching)
- **ICP Signal:** Electrical + Solar + Storage (requires licensed electrician)
- **Products:** SPAN Panel, SPAN Drive (EV charger)
- **Certification:** UL 3141 certified, requires SPAN-authorized installers
- **Scrapability:** ⚠️ Form-based, no public directory
- **Install Cost:** $7,250-8,250+
- **Notes:** First smart panel with UL 3141 PCS certification

### 2. Lumin - Smart Electrical Panels
- **URL:** https://www.luminsmart.com/partners
- **ICP Signal:** Electrical + Solar + Storage
- **Products:** Lumin Smart Panel (retrofit-compatible)
- **Certification:** Lumin Certified Installer program
- **Scrapability:** ✅ Has "Lumin Certified Installers" page
- **Install Cost:** $4,000-6,000
- **Notes:** Made in USA (Charlottesville, VA), works with any battery brand

### 3. Schneider Electric - Square D Energy Center
- **URL:** https://www.se.com/us/en/partners/partner-locator/ (EcoXpert program)
- **ICP Signal:** Electrical + Solar + Storage
- **Products:** Square D Energy Center smart panel
- **Certification:** EcoXpert certification program
- **Scrapability:** ✅ EcoXpert partner locator available
- **Notes:** World's largest electrical equipment manufacturer

### 4. Wallbox - Bidirectional EV Chargers

## Key Insights

### Multi-Trade Contractor Signals by Product Category

| Product | Primary Trade | Secondary Trade | Tertiary Trade |
|---------|---------------|-----------------|----------------|
| Smart Panels (SPAN, Lumin) | Electrical | Solar | - |
| EV Chargers (Wallbox, ChargePoint) | Electrical | Solar | - |
| Batteries (Tesla, Sonnen, FranklinWH) | Electrical | Solar | - |
| Geothermal (WaterFurnace) ✅ | HVAC | Plumbing | Electrical |
| Tankless (Rinnai, Navien) ✅ | Plumbing | HVAC | Gas |
| Heat Pumps (Daikin, Carrier) ✅ | HVAC | Electrical | - |
| Smart Thermostats | HVAC | - | - |
| Home Automation | Low Voltage | Electrical | - |
| Security/Alarm | Low Voltage | - | - |
| Roofing | Roofing | Solar | - |

### Trade Crossover Opportunities

1. **Solar + Electrical + Storage** - Highest value, full energy ecosystem
2. **HVAC + Plumbing** - Hydronic heating, tankless, geothermal
3. **Electrical + Low Voltage** - Smart home, EV, panels
4. **Roofing + Solar** - Integrated solar roofs, Tesla Solar Roof competitors
